# Expense Tracker

A simple and practical expense tracking application built to manage daily expenses in a clear and organized way.

## 🎯 Project Goal

The goal of this project is to build a small, complete, and usable expense tracker.

The application will allow users to record their expenses, manage them, and get a simple overview of their spending.

## ✨ Planned Features

- Add a new expense
- Edit an expense
- Delete an expense
- View all expenses
- Categorize expenses
- Filter expenses
- Calculate total expenses
- View basic spending information

## 🛠️ Tech Stack

- React
- TypeScript
- Vite

## 📂 Project Status

🚧 **In Development**

The project is being built step by step, from the initial setup to a complete working application.

## 🧠 Development Approach

This project is being developed with a focus on:

- Understanding the problem before implementation
- Clean and maintainable code
- Practical TypeScript usage
- Component-based React architecture
- Building features incrementally
- Keeping the project scope focused
